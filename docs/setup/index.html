For the project coordinator

Connect the study once.
Keep coding together.

The website is hosted on GitHub Pages. Your Google Sheet holds the records and codebook, and the separate decisions file holds each coder’s work.

The live study is not active until its Google Apps Script deployment URL has been configured. The practice workspace works now with fictional records.

1. Prepare the Google Sheet

Upload the original setup workbook to Drive and save it as a native Google Sheet. Keep it private: it contains the coder codes. If your university account prevents public web-app access, use an account that permits it.

2. Install the updated backend

Open Extensions → Apps Script. Replace Code.gs with the complete script linked below, save it, and run setup. Review Google’s requested permissions.

Open backend script

If you have already run setup, the script keeps the existing decisions file. You do not need to paste bridge.html separately.

3. Deploy and connect

Choose Deploy → New deployment → Web app, execute as yourself, and allow Anyone. For an existing deployment, update it to a new version. Copy the resulting URL ending in /exec.

In the repository, edit docs/ai-and-education/config.js and put that URL between the empty quotes after endpoint. Commit the change.

4. Verify before inviting coders

  1. Open the project with a coder code and save a development decision.
  2. Wait for “All your changes are saved,” then reopen with the same code in another browser. Confirm that the answer and note return.
  3. Confirm a different code cannot see that decision, and the test set remains locked.
  4. Keep the study workbook and decisions file private. Send each coder only the project page and their own code.

During coding

Edit the Codebook and Settings tabs to update wording or a deadline message. Set test_open to TRUE when the team is ready; each coder must also have completed and saved development coding.

The Progress tab shows counts. The separate decisions file remains readable by its owner, so keep it closed until your own blind coding has ended. Unresolved protocol decisions remain for the team to settle before the prompt lock.
